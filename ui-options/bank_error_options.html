Bank transfer error: pill plus inline text

Recommendation: the tile keeps its normal header, the "Action needed" pill carries the status, and the problem is written inline in the same two-line slot every other state uses. The alert card inside the tile goes. Mock-up only, Figma untouched.

Why the current one is off
1. Card in a card. A bordered, tinted alert sits inside a white tile. Same problem we removed from the card banner.
2. The tile loses its identity. No icon circle, no status pill, no PayID logo, so it no longer matches Card beside it.
3. Red appears three times (border, icon, title) and the only action, "Retry", is a small text link at the far corner.
4. Wrong tool for the scale. Banners and alerts are for page-level or blocking problems. This is one method's status, and that is what the pill is for.

Rules for the component
Pill says the state in two words. Lead line says what is wrong in plain language. Second line says why or what to do, never "Please retry" when the button already says Retry. Button is the single fix action, primary because it is the only thing to do on that tile. Page-level alert only when both methods are blocked, or the problem stops an invoice being sent.

Copy: "We couldn't set up your PayID" is good, keep it. The second line drops "Please retry." because the button covers it.
