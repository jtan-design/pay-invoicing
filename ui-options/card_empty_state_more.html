Card tile before it is added: beyond a dashed line and a ghost

Six more ways to make the empty card tile better, none of them a dashed edge or a faded ghost. Visual only, nothing built in Figma. Each one says what it signals, which source backs it, what it is built from in Pay Design System V2, and its risk.

A · Raised, not outlined

The empty tile lifts off the page with a soft shadow and no border. Active tiles stay flat, so "available" reads as something you can pick up.

Ruled out

Coloured top or side strip: design-taste bans side-stripe borders, and a top strip is the same idea and starts to look like the band. Gradient fill or glow: reads as selected or as marketing. Animated shimmer or pulse at rest: motion should show state, and this tile has none to show until the user acts.

My pick

Go with G. It enhances the card itself, adds real information (the reward and the effort) rather than decoration, and uses only Chip and Loader / Linear from Pay Design System V2, so no new component. If you want one visual treatment as well, A (raised) pairs cleanly with it. Keep F as the interaction layer in the build either way. E is the weakest.
