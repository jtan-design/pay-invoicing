Card tile before it is added: exploring the empty state

Options for how the "Available" card tile can look when nothing has been set up. Visual only, nothing built in Figma, and the band is not used. Reading from the three sources: design-taste says do not reinvent the selected state and keep contrast honest, ui-ux-pro-max says do not let "empty" look "disabled" and do not rely on colour alone, and ant-design uses a dashed treatment for "add more" actions (its dashed button is "commonly used for adding more actions").

A neutral dashed edge says "a slot waiting to be filled". The tile otherwise stays exactly like an active one.

Which to pick

Go with G if you want it to read clearly as "not added yet", or D if you want the safest, quietest option. A on its own is the cleanest dashed version. I would avoid C (close to the rejected band, and a one-off shape), E (accessibility cost) and F (card in a card). Any of A, B, D or G can be built from the existing tile plus a border and an icon change, so none needs a new component. C would need a custom shape.
